## Welcome to TechCoder

This is a sample blog post demonstrating everything you can do with the **TechCoder MDX content system**. Just drop a `.mdx` file into `content/posts/` and it appears on the site automatically.

## Adding Images

You can include images using standard markdown syntax. Images are automatically optimized with Next.js:

![Hello World Thumbnail](/content/blog/hello-world/hello-world.svg)

Store each post's images under `public/content/blog/<slug>/` — matching the
post's own slug — and reference them as `/content/blog/<slug>/your-image.svg`.
This is the same convention Keystatic uses when you upload an image from the
editor, so hand-written and editor-uploaded images stay consistent, and images
you add by hand can still be edited from `/keystatic` later without breaking.

## Code Blocks

Inline code like `console.log("Hello!")` is styled with `JetBrains Mono` in the accent color.

Fenced code blocks get the full dark-theme treatment:

```javascript
// Your first TechCoder post
const post = {
  title: "Hello World",
  category: "Tricks",
  tags: ["MDX", "TechCoder"],
};

console.log(`Welcome to ${post.title}!`);
```

Multi-language support works out of the box:

```python
def greet(name: str) -> str:
    """Greet a developer."""
    return f"Welcome to TechCoder, {name}!"

print(greet("Developer"))
```

## Lists

### Unordered

* Drop a `.mdx` file into `content/posts/`
* Add frontmatter (title, excerpt, date, category, tags, thumbnail)
* Write your content in markdown
* Done — it appears on the site

### Ordered

1. Create your image in `public/content/blog/<slug>/`
2. Reference it in frontmatter as `thumbnail: /content/blog/<slug>/my-image.svg`
3. Use `![alt text](/content/blog/<slug>/my-image.svg)` for in-body images

## How to Add a New Post

1. Create a new `.mdx` file in `content/posts/` — the filename becomes the URL slug
2. Add this frontmatter template at the top (image paths include the slug from step 1):

```yaml
---
title: "Your Post Title"
excerpt: "A brief description for cards and SEO."
date: "2026-03-21"
category: AI
tags: [Tag1, Tag2]
thumbnail: /content/blog/your-post-slug/your-thumbnail.svg
seo:
  ogImage: /content/blog/your-post-slug/your-og-image.svg
---
```

3. Write your content below the `---` using markdown or MDX
4. Save — the post appears automatically on the homepage and blog listing

That's it. **Write and ship.**
